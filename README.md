# 口袋桌游

支持局域网联机与智能人机的微信桌游小程序，包含阿瓦隆、掼蛋、斗地主和无间风云。

## 游戏

| 游戏 | 玩法与支持 |
| --- | --- |
| 阿瓦隆 | 5～10 人面对面身份推理、组队、投票与刺杀 |
| 掼蛋 | 四人两副牌、进贡抗贡、升级、逢人配与智能人机 |
| 斗地主 | 三人叫分、出牌、农民配合与智能人机 |
| 无间风云 | 身份推理、调查、装备与射击结算 |

同一 Wi-Fi 或手机热点下创建、搜索和加入房间，也可分享带房间信息的邀请卡片。
游戏业务通信走局域网；首次加载小程序、登录或微信重新获取代码仍可能需要互联网。

## 快速开始

```sh
git clone https://github.com/yugudong/pocket-game.git
cd pocket-game
npm run setup:wechat
```

在微信开发者工具中导入 `miniprogram/`，项目类型选择“小程序”。公共模板使用 `touristappid`；需要真机调试或上传时，在本机生成的 `miniprogram/project.config.json` 中填写自己的 AppID。该文件不入库，已有配置不会被初始化命令覆盖。
普通编译即可运行，不需要 npm 构建或业务服务器。真机调试、预览和上传需要自己的开发者权限。

使用 Node.js 22 或更高版本，在根目录验证：

```sh
npm run check
npm test
```

## 项目结构

```text
miniprogram/       小程序运行源码、规则、人机、局域网会话和页面
tests/             回归测试与牌局夹具
tools/             检查、编译、打包、基准和复盘工具
  fixtures/        用于人机对照的旧版策略快照
  runtime/         可选微信自动化依赖清单
assets/            头像源素材
docs/              玩法、开发说明和精选验证记录
.github/workflows/ Windows / Linux 自动检查
```

`dist/`、`output/`、本机依赖、微信私有配置和浏览器缓存均不入库。
真实 AppID 和 AppSecret 不写入公开源码；检查命令会拒绝已跟踪文件中的真实 AppID。

## 版本与验证

当前代码基线为 **1.6.10**。掼蛋已增加保留大单、大对与炸弹的出牌顺序判断，保留必要拦截、对家配合和两手收尾。
该版本此前通过 182 项相关测试与微信官方编译；对旧版 1.6.9 的 200 副内部对照为 103 胜（51.5%）、净升级 +28，不代表稳定胜率或真人胜率。

最后由用户确认上传的微信体验版为 **1.6.2**；本仓库的版本、提交和标签不代表已上传或已发布。
